# Veo Scooter Budget & Route Logger

## Project Goal
A tool to quickly track Veo scooter micro-transactions, calculate total transit spending, and analyze the most frequent campus routes.

## Tech Stack
- Bash
- Standard Unix text processing tools (awk, grep, sort, uniq)

## MVP Scope (Do)
- Command to append a new trip entry to a local CSV file.
- Command to calculate and print all-time total spending.
- Command to output a ranked list of the most frequently taken routes.

## Future Plans
- Filter spending by specific timeframes.
- Calculate average cost-per-ride.
- Track ride duration to calculate transit efficiency.
